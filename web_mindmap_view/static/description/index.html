Core Capabilities

Everything you need to bring hierarchical Odoo data to life.

Infinite Canvas

Pan and zoom freely across an unlimited workspace. Navigate large data hierarchies without losing context.

One2many Field Widget

Embed the mind map directly inside any Form View as a one2many widget. Visual sub-record management with zero overhead.

Smart Expand / Collapse

Set a default_depth parameter and let users expand or collapse any branch on demand — ideal for very deep trees.

Native Dark Mode

Fully integrated with Odoo's native dark theme. Canvas, nodes, and UI elements all adapt automatically.

Inline Side Panel

Click the gear icon on any node to open a contextual side panel for instant record editing without leaving the map.

Node Color Coding

Assign colors to nodes for quick visual tagging, prioritization, and category grouping across the hierarchy.

1. Full Hierarchy Overview

Every record in your recursive model becomes a node. Root records sit at the center; branches and leaves fan out automatically. The layout engine handles thousands of nodes gracefully, giving you a complete bird's-eye view of your data structure at a glance.

2. Native Dark Mode

The canvas is built with Odoo's theming system. When your users switch to dark mode in their preferences, the entire mind map — background, nodes, connectors, and panels — transitions seamlessly. No extra configuration needed.

3. Embedded Form View Widget

Use <field widget="mindmap"> inside any standard form view to render a One2many relationship as a mind map. Ideal for task dependencies, BOM components, project sub-tasks, and any parent-child data structure.

4. Live Editing via Side Panel

Clicking the gear icon on a node opens a sleek slide-in panel. Fields listed in side_panel_fields become instantly editable. Changes are saved and reflected across the canvas without a page reload.

5. Context Menu & Color Tags

Right-clicking a node reveals a contextual menu to add a child node or delete the branch. Each node also supports color assignment for quick visual categorization — perfect for priority tagging and status grouping.

6. Depth-Controlled Expansion

Configure the initial visible depth with the default_depth attribute. Users can expand or collapse individual branches on the fly — keeping the view clean whether your tree spans 3 levels or 30.

Developer Quick-Start

Add the mindmap view type to any Odoo model in minutes using the arch attributes below.

<mindmap parent_field="parent_id" child_field="child_ids" default_depth="2" side_panel_fields="name,description" settings_view_id="my_module.my_record_form"> <field name="name"/> <field name="description"/> </mindmap>
parent_field

Many2one field pointing to the parent record, e.g. parent_id.

child_field

One2many field listing child records, e.g. child_ids.

default_depth

Number of levels to expand on initial load. 0 = show all.

side_panel_fields

Comma-separated field names shown/edited in the side panel.

settings_view_id

External ID of the form view to open when clicking a node's full-edit button.
